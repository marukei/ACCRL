# コンテンツ創作でのACCRL適用例

このディレクトリには、文章、画像、音楽などのコンテンツ創作においてACCRLを適用する実例を収録しています。

## 基本的な適用方法

### 1. 作品への表記

#### 文章作品の例
```markdown
---
タイトル: AI時代の物語
著者: 山田花子
ライセンス: ACCRL-1.0
AI協働: あり（Claude 3.5）
透明性レベル: 3
---

本作品は人間とAIの協働により創作されました。
AIの学習に使用された無数の文学作品の作者の方々に敬意を表します。
```

#### 画像作品の例
```
作品タイトル: 未来都市
クリエイター: 田中一郎
使用AI: Midjourney v6, DALL-E 3
ライセンス: ACCRL-1.0

【創作プロセス】
- プロンプト作成: 人間
- 画像生成: AI（15回の反復）
- 最終選択と編集: 人間
```

### 2. 透明性記録の詳細

## ブログ記事での適用例

```markdown
# AIと考える持続可能な社会

*本記事はClaude 3.5との対話を通じて作成されました。*

## 記事情報
- 執筆者: 佐藤次郎
- AI協働者: Claude 3.5 (Anthropic)
- 作成日: 2025年7月15日
- 透明性レベル: 4（完全な対話ログを公開）

## 創作プロセス

### 1. 初期構想（人間）
持続可能な社会についての記事を書きたいと考え、以下のテーマを設定：
- 環境問題の現状
- テクノロジーの役割
- 個人ができること

### 2. AI協働での構成作成
Claudeと3回の対話を通じて記事構成を練り上げた。
- 第1回: 大まかな流れの相談
- 第2回: 各セクションの詳細化
- 第3回: 導入部分の推敲

### 3. 執筆プロセス
- 導入: 人間が執筆
- 本論: AIの提案を基に人間が大幅に編集
- 結論: 人間が執筆
- 全体推敲: AIの文法チェックを参考に

### 4. 最終判断
すべての内容について、事実確認と価値判断は人間が行った。

## 対話ログ
[完全な対話ログはこちら](./dialogue-log-20250715.md)

---

## 本文
[記事本文...]

---

## 謝辞
この記事の作成にあたり、Claudeの学習データとなった無数の執筆者の方々、
特に環境問題について発信してこられたすべての方々に感謝いたします。
```

## 小説創作での適用例

### 作品ファイルの構成
```
my-novel/
├── LICENSE.md (ACCRL)
├── README.md
├── TRANSPARENCY.md
├── manuscript/
│   ├── chapter-01.md
│   ├── chapter-02.md
│   └── ...
├── creation-process/
│   ├── character-development.md
│   ├── plot-outline.md
│   └── ai-collaboration-log.md
└── acknowledgments.md
```

### TRANSPARENCY.md の例
```markdown
# 「〇〇物語」創作プロセス記録

## 基本情報
- 作品名: 〇〇物語
- 著者: 鈴木太郎
- ジャンル: SF小説
- 執筆期間: 2025年4月〜7月

## AI協働の詳細

### 使用AI
- ChatGPT-4: プロット相談、世界観構築
- Claude 3.5: 文章推敲、対話文作成補助

### 協働の性質: 対等協働型

## 創作における人間の判断

### 1. 世界観設定
- **AIの提案**: 5つの異なるSF設定を生成
- **人間の選択**: 「時間ループもの」を選択
- **理由**: 個人的な体験と重ね合わせられるテーマ

### 2. キャラクター造形
- **主人公の性格**: 完全に人間が創造
- **脇役の設定**: AIの提案を参考に人間が深化
- **名前**: 日本の伝統的な命名法を人間が適用

### 3. プロット展開
- **基本構造**: 人間が起承転結を設定
- **詳細展開**: AIと10回のブレストセッション
- **クライマックス**: 人間の直感で決定

### 4. 文体と表現
- **基調**: 人間が確立
- **推敲**: AIの提案を参考に
- **最終稿**: すべて人間が確定

## 具体的な協働例

### 第3章の冒頭（ビフォー・アフター）

**初稿（人間）**:
「朝日が窓から差し込んだ。」

**AI提案**:
「朝日が窓から差し込み、部屋を金色に染めた。」

**最終稿（人間の判断）**:
「朝日が割れた窓から差し込み、埃の粒子を金色に輝かせた。」

→ AIの「金色」という表現は採用したが、「割れた窓」と「埃の粒子」で
  荒廃した世界観を人間が追加。

## 創作比率（推定）
- プロット: 人間70% / AI30%
- 文章: 人間85% / AI15%
- 推敲: 人間60% / AI40%
```

## 音楽制作での適用例

```yaml
# 楽曲メタデータ (music-metadata.yaml)
title: "Digital Dreams"
artist: "山田ミュージック"
license: "ACCRL-1.0"
ai_collaboration:
  used: true
  tools:
    - name: "Suno AI"
      role: "メロディ生成"
    - name: "ChatGPT"
      role: "歌詞作成補助"
transparency_level: 3

creation_process:
  concept: "人間が「デジタル時代の夢」というテーマを設定"
  melody: "Suno AIで10パターン生成、人間が選択・編曲"
  lyrics: "ChatGPTとのブレストを基に人間が作詞"
  arrangement: "人間がDAWで最終アレンジ"
  
acknowledgment: |
  この楽曲は、AIの学習に使用された
  すべての音楽作品の作曲家・作詞家の方々の
  創造性の上に成り立っています。
```

## ポッドキャスト/動画での適用例

### 番組説明文
```markdown
# ポッドキャスト「AI時代の創作論」

## 番組情報
- ホスト: 田中ポッドキャスター
- 配信: 毎週水曜日
- ライセンス: ACCRL-1.0

## AI協働について
本番組では以下のAIツールを使用しています：
- 文字起こし: Whisper AI
- 要約作成: Claude 3.5
- サムネイル生成: DALL-E 3

### 人間の創作的判断
- 企画・構成: 100%人間
- ゲスト選定: 100%人間  
- 編集判断: 100%人間
- AIは補助ツールとしてのみ使用

## エピソードごとの透明性記録
各エピソードのShow Notesに、
そのエピソードでのAI使用状況を記載しています。

## 謝辞
音声認識技術の基礎となった研究者の方々、
要約技術の学習データとなった無数のテキストの執筆者の方々に
感謝いたします。
```

## ベストプラクティス

### 1. クレジット表記の標準化
```
標準フォーマット:
作品名: [タイトル]
創作者: [人間の名前]
AI協働: [使用したAI]
ライセンス: ACCRL-1.0
透明性レベル: [1-4]
```

### 2. プロセス記録の習慣化
- 創作日誌をつける
- AIとの対話を保存
- 判断理由をメモ

### 3. コミュニティでの共有
- 創作プロセスの公開
- 失敗例も含めて共有
- 技法の文書化

## FAQ

**Q: 趣味の創作でも適用すべき？**
A: 規模に関わらず、透明性は創作文化の健全性に貢献します。

**Q: SNS投稿にも必要？**
A: 可能な範囲で。ハッシュタグ #ACCRL などで簡潔に示すことも可。

**Q: 過去作品への遡及適用は？**
A: 必須ではありませんが、主要作品については追記を推奨。
