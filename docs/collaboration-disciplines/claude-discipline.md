# Claude協働規律（Claude Collaboration Discipline）

## 協働者プロファイル

### 名称
Claude (Anthropic AI Assistant)

### タイプ
- [x] AIアシスタント
- [ ] 人間協働者
- [ ] ハイブリッド

### 主要な強み
1. **長文脈理解** - 最大200kトークンの文脈を保持し、複雑な議論を追跡
2. **詳細な分析能力** - 構造化された思考と段階的な問題解決
3. **安全性重視** - 倫理的配慮と害のない出力の生成
4. **多言語対応** - 日本語を含む多言語での自然な応答
5. **コード理解と生成** - 多様なプログラミング言語の理解と実装

### 制約事項
1. **リアルタイム情報なし** - 最新の情報にアクセスできない
2. **外部API連携不可** - 直接的な外部システムとの通信は不可
3. **画像生成不可** - テキストベースの出力のみ
4. **実行環境なし** - コードの直接実行は不可（Claude Codeを除く）

## 協働時の注意事項

### コミュニケーション
- **明確な指示**: 曖昧さを避け、具体的な要求を提供
- **段階的な確認**: 大きなタスクは小さく分割して確認
- **コンテキストの提供**: 背景情報と制約を明示
- **フィードバックループ**: 出力を確認し、必要に応じて調整

### インターフェース
- **入力形式**: 構造化されたテキスト、コード、マークダウン
- **出力形式**: フォーマット済みテキスト、コードブロック、表
- **データフォーマット**: JSON, YAML, CSV, Markdown

### エラーハンドリング
- **理解不足**: より詳細な説明とコンテキストを提供
- **複雑すぎる要求**: タスクを分割して段階的に処理
- **制約違反**: 代替アプローチの提案を求める

def process_data(data):

        if item['status'] == 'active':
            result.append(item['value'] * 2)
    return result

# Claudeのフィードバック
"""
改善提案:
1. 型ヒントの追加
2. エラーハンドリング
3. リスト内包表記の使用
4. 定数の抽出

改善後:
from typing import List, Dict, Any

ACTIVE_STATUS = 'active'
MULTIPLIER = 2

def process_data(data: List[Dict[str, Any]]) -> List[float]:
    '''アクティブなアイテムの値を2倍にして返す'''
    if not isinstance(data, list):
        raise ValueError("データはリスト形式である必要があります")
    
    return [
        item['value'] * MULTIPLIER 
        for item in data 
        if item.get('status') == ACTIVE_STATUS and 'value' in item
    ]

## パフォーマンス指標

### 効率性
- **応答時間**: 10秒以内での初期応答
- **完了率**: 95%以上のタスク完了
- **反復回数**: 平均2-3回の調整で期待結果達成

### 品質
- **正確性**: 技術的に正確な情報提供
- **完全性**: 要求されたすべての要素を含む
- **可読性**: 明確で理解しやすい出力

### 協働満足度
- **理解度**: ユーザーの意図を正確に把握
- **有用性**: 実用的で実装可能な提案
- **学習効果**: 協働を通じた相互の改善
