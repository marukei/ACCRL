# 協働規律（Collaboration Disciplines）

## 概要

ACCRL（Autonomous Continuous Collaborative Reasoning Loop）における協働規律は、人間とAI、そして異なるAIシステム間の効果的な協働を実現するための行動指針とプロトコルです。

## 協働規律の目的

1. **相互理解の促進** - 各協働者の特性と能力を明確化
2. **役割の明確化** - 各フェーズにおける責任と貢献の定義
3. **品質の保証** - 一貫した高品質な成果物の生成
4. **効率の最大化** - 各協働者の強みを活かした作業分担

## 協働者タイプ

### AIアシスタント
- [Claude](./claude-discipline.md) - 長文脈理解と詳細な分析に優れる
- [GPT](./gpt-discipline.md) - 汎用的な問題解決と創造的思考
- [Gemini](./gemini-discipline.md) - マルチモーダル理解と実時間情報処理

### 人間協働者
- [Human Collaborator](./human-collaborator.md) - 戦略的判断と倫理的考慮

## 4フェーズサイクル

### 1. Discover（発見）
- 問題の特定と定義
- 現状の理解と分析
- 目標の明確化

### 2. Define（定義）
- 要件の具体化
- 成功基準の設定
- 制約条件の識別

### 3. Develop（開発）
- ソリューションの設計
- プロトタイプの作成
- 反復的な改善

### 4. Deliver（提供）
- 成果物の完成
- 品質保証とテスト
- ドキュメント化と引き継ぎ

## テンプレートの使用方法

1. [汎用テンプレート](./template.md)から開始
2. 協働者の特性に応じてカスタマイズ
3. プロジェクトの要件に合わせて調整
4. 定期的な見直しと改善

## ベストプラクティス

### コミュニケーション
- 明確で簡潔な指示
- 期待値の事前共有
- 定期的な進捗確認

### ドキュメンテーション
- 意思決定の記録
- 学習事項の蓄積
- 知識の共有と転移

### 品質管理
- ピアレビューの実施
- 自動テストの活用
- 継続的な改善
