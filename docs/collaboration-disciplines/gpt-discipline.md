### 名称
GPT (OpenAI Assistant)

### タイプ
- [x] AIアシスタント
- [ ] 人間協働者

### 主要な強み
1. **汎用的問題解決** - 幅広いドメインでの柔軟な対応
2. **創造的思考** - 革新的なアイデアと解決策の生成

// リクエスト: "React Hooksを使用したカスタムフック for API呼び出し"

import { useState, useEffect } from 'react';

function useApiCall(url, options = {}) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        setLoading(true);
        const response = await fetch(url, options);
        if (!response.ok) throw new Error(`HTTP error! status: ${response.status}`);
        const jsonData = await response.json();
        setData(jsonData);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
}

// 使用例とテストケースも同時に生成

## 協働時の注意事項

### コミュニケーション
- **明確なプロンプト**: 期待する出力形式を具体的に指定
- **段階的な詳細化**: 概要から詳細へ段階的に質問
- **文脈の再確立**: 長い会話では定期的に文脈を要約
- **温度パラメータの調整**: タスクに応じて創造性レベルを調整

### インターフェース
- **入力形式**: 自然言語、コード、構造化データ
- **出力形式**: テキスト、コード、表、図（テキストベース）
- **データフォーマット**: JSON, XML, YAML, Markdown

### エラーハンドリング
- **幻覚（Hallucination）**: 事実確認と検証の実施
- **文脈の喪失**: 要約と再確認で対処
- **不適切な出力**: プロンプトの改善と制約の明確化
