## 決定内容

### 決定1: v0.3 の設計を承認する

**人間創作者の判断**: 「承認します」

「法的に拘束されるのは採用者だけ」「規範は著作権に依存しない」という v0.3 の二つの原則と、第I部（採用者の許諾と約束）・第II部（誓約と呼びかけ）の構造が、2026-08-12 の「器はライセンス、実態は誓約」の決定と一致するものとして承認された。

### 決定2: 人格権は「意図的な沈黙」とする（open-questions Q5 の決着）

**人間創作者の判断**：

> 曖昧さを残す（法律問題なので）というのはどうでしょう。人格権の不行使を宣言することはリスクを孕み、かといって行使することを明言するのも萎縮させるからです。

**判断の構造**（AI による整理）：

- Claude Code が起草時に立てた問いは「任意の不行使宣言を既定で付すか、付さないか」という二択だった。人間創作者は、この二択の外にある第三の答えを示した
- **不行使の宣言**は、創作者が人格権という盾を手放す危険を孕む（人格権軸を損なう）
- **行使の明言**は、利用者を萎縮させる（非強制軸を損なう）
- **どちらも明言しない**ことで、二つの軸が両立する。人格権は法律の問題であり、その扱いは法律と個々の状況に委ねる
- この曖昧さは、未整理の結果ではなく選択である。ACCRL は「解決していないことを明示する」ことを誠実さの根幹にしてきたが、ここでの沈黙は「解決していない」のではなく、「ライセンスが決めるべきでないことを、ライセンスが決めない」という判断である

**反映**：

- v0.3 第5条を「5.1 人格権は許諾も放棄もされない」「5.2 意図的な沈黙」に改めた
- 起草時の任意の不行使宣言（第5.2条・付録B）を削除し、付録を繰り上げた
- 第11条4項の「創作者が法律上当然に持つ権利の行使を妨げない」を、行使を示唆しない「法律上持つ権利について何も定めない」に改めた
- 承認前の草案は git 履歴（コミット 9ec04eb）に残る

### 決定3: 本プロジェクト自身のライセンスを v0.3 に切り替える

**人間創作者の判断**: 「切り替える方向でお願いします」

v0.3 の論理では、採用の表明は採用者の誓約であり、誓約できるのは人間だけである（第1条4号）。そのため Claude Code は起草時に LICENSE を v0.1 のまま残し、判断を人間創作者に委ねていた。

**反映**：

- LICENSE を v0.3 の採用の表明に書き換えた。採用者の誓約（第6条）は、人間創作者の一人称の誓約として記述し、AI協働者は誓約を行わないことを明記した
- AI学習の留保（第2.2条）は付さない。これは v0.1 期の自己適用（「ACCRL の理念に賛同する限りにおいて AI 学習に利用できる」）の趣旨を、条件ではなく呼びかけとして引き継いだものである
- 2025-07-05 から 2026-09-29 までに公開したものを含む全体を、v0.3 の下でも提供すると明記した
- 採用者名は、v0.1 期の LICENSE と同じく「[人間創作者名]」のままにしてある。記名するかどうかは人間創作者が決める

## 収束

決定2は、この協働で繰り返し現れた型を示している。AI（Claude Code）は、問題を「どちらを選ぶか」という形に整理し、選択肢を提示した。人間創作者は、その問いの立て方自体がどちらかの軸を損なうことを見抜き、「決めないことを決める」という答えを示した。

これは 2026-08 のレビューセッションで記録された AI の誤り——非強制の設計を「強制力の欠如」という欠陥として数えたこと——と同じ根を持つ。AI は、明言されていないことを「未解決」や「欠陥」として扱いやすい。しかし、非強制を軸とする文書にとって、明言しないことは設計の一部でありうる。
