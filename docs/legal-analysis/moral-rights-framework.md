# 著作者人格権の法的フレームワーク

**作成日**: 2025年7月15日  
**作成者**: 人間創作者 + Claude（AI協働）

## 概要

本文書は、AI Collective Creativity Respect License (ACCRL) の中核概念である「著作者人格権」について、その法的基盤と国際的適用可能性を分析するものです。

## 1. 著作者人格権とは

### 1.1 基本概念

著作者人格権（Moral Rights / Droit Moral）は、著作者が自己の著作物に対して持つ人格的利益を保護する権利です。経済的権利（著作財産権）とは独立して存在し、以下の特徴を持ちます：

- **一身専属性** - 譲渡不可能
- **不可侵性** - 放棄不可能（多くの法域において）
- **永続性** - 著作財産権の保護期間を超えて存続する場合がある

### 1.2 主要な権利内容

1. **公表権** - 著作物を公表するか否か、いつ、どのような方法で公表するかを決定する権利
2. **氏名表示権** - 著作者名の表示方法を決定する権利
3. **同一性保持権** - 著作物の改変を禁止する権利
4. **名誉声望権** - 著作者の名誉・声望を害する利用を禁止する権利（一部法域）

## 2. 各国法域での扱い

### 2.1 日本（強い保護）

**日本国著作権法**における人格権：
- 第18条：公表権
- 第19条：氏名表示権
- 第20条：同一性保持権
- 第113条6項：名誉声望を害する利用の禁止

**特徴**:
- 著作者人格権は一身専属で譲渡・放棄不可
- 著作者の死後も一定の保護（遺族による権利行使）
- 「やむを得ない改変」の例外は限定的

### 2.2 欧州（ベルヌ条約準拠）

**ベルヌ条約第6条の2**:
> 「著作者は、その財産的権利とは別個に、この権利が譲渡された後においても、著作物の創作者であることを主張する権利及び著作物の変更、切除その他の改変又は著作物に対するその他の侵害で自己の名誉又は声望を害するおそれのあるものに対して異議を申し立てる権利を保有する」

**EU各国の実装**:
- フランス：最も強い保護（永久不滅の権利）
- ドイツ：包括的な人格権保護
- イギリス：限定的だが存在

### 2.3 米国（限定的保護）

**Visual Artists Rights Act (VARA) 1990**:
- 視覚芸術作品に限定
- 帰属権と同一性保持権のみ
- 放棄可能

**特徴**:
- 一般的な著作物には人格権保護なし
- フェアユース優先の文化
- 契約による処理が一般的

### 2.4 その他の地域

- **カナダ**：ベルヌ条約準拠、放棄可能
- **オーストラリア**：2000年に人格権導入
- **中国**：人格権保護あり、ただし執行に課題
- **インド**：ベルヌ条約準拠の保護

## 3. AI協働における人格権の新しい意義

### 3.1 従来の人格権の限界

1. **人間中心主義** - AI創作物には適用困難
2. **個人主義** - 集合的創作への対応不足
3. **静的保護** - 動的な協働プロセスを想定せず

### 3.2 ACCRLによる拡張概念

1. **協働人格権** - 人間とAIの協働における人間の創作的人格の保護
2. **集合的人格権** - AI学習データ提供者たちの集合的な人格的利益
3. **プロセス人格権** - 創作過程における判断・選択の透明性確保

## 4. 国際的適用可能性の分析

### 4.1 課題

1. **法域間の差異**
   - 米国：人格権軽視、フェアユース重視
   - 欧州：人格権重視、著作者保護強い
   - アジア：多様（日本は強い、他は様々）

2. **既存の国際条約との整合性**
   - ベルヌ条約：最低限の人格権保護を要求
   - TRIPS協定：人格権は対象外
   - WIPO条約：限定的言及

### 4.2 ACCRLの戦略

1. **最小公倍数アプローチ**
   - ベルヌ条約6条の2を基礎とする
   - 各法域で実現可能な最低限の保護

2. **契約的補完**
   - 法的保護が弱い地域では契約で補強
   - ライセンス条項として人格権尊重を要求

3. **文化的架橋**
   - 日本的価値観を普遍的言語で表現
   - フェアユース文化圏への配慮条項

## 5. 実装提案

### 5.1 コア条項

```
1. 創作者人格権の承認
   本ライセンスの下で提供される著作物に関し、利用者は創作者の
   人格的利益を尊重することに同意する。

2. 最小限の人格権保護
   法域に関わらず、以下を保証する：
   a) 帰属の正確な表示
   b) 創作意図に反する改変の制限
   c) 名誉・声望を害する利用の禁止

3. AI協働の透明性
   AI協働作品においては、人間の創作的判断を明示する。
```

### 5.2 法域別の調整条項

```
4. 法域別適用
   a) 人格権保護が強い法域：当該法域の法に従う
   b) 人格権保護が弱い法域：本ライセンスが最低限の保護を提供
   c) 抵触する場合：創作者に有利な解釈を採用
```

## 6. 結論

著作者人格権は、AI協働時代において新たな意義を持ちます。ACCRLは、この概念を拡張・進化させることで、以下を実現します：

1. **人間の創作的尊厳の保護** - AI協働でも人間性を保持
2. **見えない貢献者への敬意** - 集合的人格権の概念化
3. **国際的な架橋** - 多様な法文化の調和

人格権アプローチは、著作権アプローチでは対応できないAI時代の課題に、倫理的かつ実践的な解決策を提供します。
