# 既存オープンソースライセンスの比較分析

**作成日**: 2025年7月15日  
**作成者**: 人間創作者 + Claude（AI協働）

## 概要

本文書は、AI Collective Creativity Respect License (ACCRL) の開発にあたり、既存の主要オープンソースライセンスを分析し、AI協働時代における各ライセンスの限界と、ACCRLが解決を目指す課題を明確化するものです。

## 1. 分析対象ライセンス

### 1.1 MIT License
**特徴**:
- 最も寛容なライセンスの一つ
- 著作権表示とライセンス表示の保持のみを要求
- 商用利用、改変、再配布が自由

**AI協働における限界**:
- 著作権（Copyright）前提のため、AI生成物の権利帰属が不明確
- 創作プロセスの透明性要求なし
- AI学習データ提供者への配慮条項なし

### 1.2 Apache License 2.0
**特徴**:
- 特許権の明示的許諾を含む
- 変更箇所の明示を要求
- NOTICE ファイルによる属性表示

**AI協働における限界**:
- 依然として著作権ベースのアプローチ
- AI協働の透明性に関する規定なし
- 「貢献者」の定義が人間前提

### 1.3 GNU GPL v3
**特徴**:
- 強力なコピーレフト（感染性）
- ソースコード開示義務
- ユーザーの自由を最大限保護

**AI協働における限界**:
- 「作品」の定義がAI協働を想定していない
- 感染性が強すぎてAI協働プロジェクトに不向き
- 技術的保護手段の禁止がAIサービスと相性が悪い

### 1.4 Mozilla Public License 2.0
**特徴**:
- ファイル単位のコピーレフト
- 特許権条項を含む
- 他ライセンスとの互換性に配慮

**AI協働における限界**:
- 「コントリビューター」がAIを想定していない
- ソースコード形式の定義がAIモデルに適用困難
- 創作プロセスの透明性要求なし

## 2. 著作権アプローチ vs 人格権アプローチ

### 2.1 既存ライセンスの共通点：著作権中心主義

すべての既存ライセンスは以下の前提に立っています：
1. **著作権の存在を前提** - 「Copyright (c) 年 著作権者」という表記
2. **経済的権利の処理が中心** - 複製、改変、配布の許諾
3. **人格的権利への言及が限定的** - せいぜい帰属表示（Attribution）程度

### 2.2 ACCRLの革新：人格権中心主義

ACCRLは以下の点で根本的に異なります：
1. **著作者人格権を基軸** - 創作者の人格的発露を最高価値とする
2. **経済的権利は副次的** - 人格権尊重の結果として処理
3. **「見えない貢献者」への配慮** - AI学習データ著作者の人格権も考慮

## 3. コピーレフト性の比較

| ライセンス | コピーレフト強度 | 感染性 | 他ライセンスとの互換性 |
|-----------|----------------|-------|---------------------|
| MIT | なし | なし | 高い |
| Apache 2.0 | なし | なし | 高い |
| GPL v3 | 強い | あり（全体） | 限定的 |
| MPL 2.0 | 中程度 | あり（ファイル単位） | 中程度 |
| **ACCRL（構想）** | **中程度** | **なし** | **高い** |

### 3.1 ACCRLのコピーレフト設計思想

- **人格権尊重の継承は必須** - 派生作品も人格権尊重ルールを継承
- **感染性は持たない** - 他のコードとの組み合わせを妨げない
- **理念の伝播を重視** - 法的強制力より倫理的影響力

## 4. AI協働における各ライセンスの問題点まとめ

### 4.1 共通の問題点
1. **AI生成物の権利帰属が不明確**
   - 「著作者」の定義が人間前提
   - AI協働のケースを想定していない

2. **透明性要件の欠如**
   - AIツール使用の開示義務なし
   - 人間の創作的判断の明示要求なし

3. **学習データへの配慮なし**
   - AI学習に使われたデータの著作者への言及なし
   - 「見えない貢献」の概念が存在しない

### 4.2 個別の問題点

**MIT/Apache**: 
- 寛容すぎてAI企業による一方的利用を防げない

**GPL**:
- 感染性が強すぎてAI協働プロジェクトの実用性を損なう

**MPL**:
- ファイル単位の区分がAI協働作品に適用困難

## 5. ACCRLが解決を目指す課題

1. **創作者人格権の明確な保護**
   - AI協働でも人間の創作的人格を保護
   - 創作思想・美学・意図の尊重義務

2. **透明性の義務化**
   - AI使用の明示
   - 人間の判断・選択・修正プロセスの記録

3. **エコシステム全体への配慮**
   - AI学習データ著作者への敬意
   - 文化的創作の連鎖を意識した設計

4. **実用的なコピーレフト**
   - 理念は継承、コードは自由
   - 他ライセンスとの共存可能

## 6. 結論

既存のオープンソースライセンスは、20世紀の著作権パラダイムに基づいて設計されており、AI協働時代の創作活動に十分対応できていません。ACCRLは、著作者人格権を中心に据えることで、この限界を突破し、AI時代にふさわしい新しい創作倫理の枠組みを提供することを目指します。
